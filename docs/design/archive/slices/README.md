# 切片生命周期产物归档

本目录存放所有已完成（G4）切片的生命周期产物，包括：

- `*-baseline.md`：实施基线包（G1 冻结产物）
- `*-g3-g4-closeout.md`：G3/G4 合并完成收口记录
- `*-corrective-checkpoint.md`：执行期纠偏检查点
- `*-checkpoint.md`：阶段性里程碑检查点

## 归档触发规则

**G4 完成 = 归档触发**：切片的 `*-g3-g4-closeout.md` 写完并 commit 后，该切片所有生命周期产物须在同一 commit 或紧跟 commit 中迁移至本目录。

不触发归档的文件（永久驻留 `docs/design/` 根层）：

- `phase2-development-execution-tracker.md`（持续维护的执行看板）
- `api-route-canonical-inventory.md`（永久 SSOT，随新路由持续更新）
- 所有 `phase2-*.md` 业务域设计文档（长期有效的设计参考）

## 命名格式

文件名保持原始切片命名，不做重命名。按切片编号（`ex-NN`、`fe-NN`）可直接通过文件名定位。
