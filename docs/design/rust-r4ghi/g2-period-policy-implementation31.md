# 期末与当前依据的裁决补充

用户已选择“实时维护当前，期末保留期间历史”，实际裁决记录为 [user-decision-period05.json](./user-decision-period05.json)。原纠偏01第6、11项中的待裁决状态是历史记录，以本补充为准。原G1原件不改写；不新增HTTP或schema。

现有正常期间捕获使用 `paired_period_id.is_none()` 决定是否选择为当前。期间捕获保留当前快照ID，仅推进真实并发版本；H只对真正当前快照发布active绑定。期间终端不得提升为实时当前；真实来源纠正若同时影响多个实时或期间终端，仍按完整实际影响闭包分别重述，并按各自当前关系更新。补关本身不能让看板或提成依据回退到历史期间。

验收准入改为核对实际裁决文件的固定字节SHA和新source epoch中的同一pin；请求中的approved或decision7Approved布尔值仍无效。日期、来源资格、权限、CAS、完整影响闭包、必要审计及身份写入规则保持执行。

当前只是策略与准入接线。关账、期间重述、无实时快照、补关后看板及四阶段绑定不回退的真实PG/HTTP验收尚未完成，G3/G4为false。不得改服务器时间、SQL造历史资格或将早先只读preparation当作关账通过。
